# kit-epic

Будущий кит LADO, который ведёт эпик от начала до конца: исследование → план из маленьких
проверяемых шагов → шаги по очереди (каждый — задача трекера, выполняемая китом
[sdlc](https://github.com/ladohq/kit-sdlc)) → пересмотр плана после каждого шага.

Пока кита нет: здесь журналы эпиков, которые ведутся руками, как материал для его
формализации.

- `journal/docker-install.md` — эпик «установка LADO через Docker» (`ladohq/lado`, LAD-52 и
  дальше).
- `docs/brief.md` — бриф для kit-builder: с чего строить кит (задача LAD-103).
- `.lado/tracker.yaml` — доска Yougile для кита tracker-yougile.
